# Сугуру для Дали

Головоломка Сугуру 9×9 для iPhone: бесконечный генератор головоломок с единственным решением, три уровня сложности, заметки, отмена ходов и подсказки с объяснением.

Правила: в области из N клеток стоят числа от 1 до N, каждое по одному разу. Одинаковые числа не касаются друг друга, даже по диагонали.

## Как устроено

- `index.html` — готовая игра (собирается скриптом, руками не править).
- `src/engine.js` — генератор и решатель.
- `src/app.js` — интерфейс. Условие получения подсказки задаётся в объекте `HintGate` в начале файла.
- `src/top.html` — стили и разметка.
- `sw.js`, `manifest.webmanifest`, иконки — чтобы игру можно было добавить на экран «Домой» и играть без интернета.

После правок в `src/` выполнить `python3 src/build.py` и поменять версию кэша в `sw.js`.
