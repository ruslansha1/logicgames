# Головоломки для Дали

Логические игры для iPhone, переключаются кнопкой «Игры» в шапке. Прогресс каждой игры хранится отдельно.

**Сугуру 9×9.** В области из N клеток стоят числа от 1 до N, каждое по одному разу. Одинаковые числа не касаются друг друга, даже по диагонали.

**Судоку 12×12.** Блоки 3×4, числа 1–12. В каждой строке, столбце и блоке все 12 чисел без повторов.

В обеих играх: бесконечный генератор головоломок с единственным решением, три уровня сложности, заметки, отмена ходов, подсветка ошибок и подсказки с объяснением.

**Профили и достижения.** Кнопка с аватаром в шапке открывает профиль: несколько игроков на одном устройстве, у каждого свои партии, победы, точность ходов, подсказки, время и витрина достижений с уровнями от бронзы до бриллианта. Всё хранится локально (localStorage), без сервера.

## Как устроено

- `index.html` — готовое приложение (собирается скриптом, руками не править).
- `src/common.js` — общее: шторка, сердечки, условие получения подсказки (объект `HintGate`, одно на все игры).
- `src/engine.js`, `src/app.js` — Сугуру: генератор/решатель и интерфейс.
- `src/sudoku-engine.js`, `src/sudoku-app.js` — Судоку 12×12: генератор/решатель и интерфейс.
- `src/profile.js` — профили игроков (`Profiles`): ключи хранилища получают суффикс `@<id профиля>`, старые данные при первом запуске переезжают в первый профиль.
- `src/achievements.js` — статистика и достижения (`Track`), витрина и окно профиля. Игра сообщает о событиях вызовами `Track.start/move/hint/tick/win` и подключается строкой `Track.register(id, { title, speed })`: после этого у неё появляются своя статистика, три собственных достижения и раздел в витрине, а общие достижения начинают учитывать её автоматически.
- `src/shell.js` — переключение между играми.
- `src/top.html` — стили и разметка.
- `sw.js`, `manifest.webmanifest`, иконки — чтобы приложение можно было добавить на экран «Домой» и играть без интернета.

После правок в `src/` выполнить `python3 src/build.py` и поменять версию кэша в `sw.js`.
